# Edit saved travelers

Signed-in users can now edit a saved traveler on the Account page.

- Each saved traveler on the Account page has an Edit button.
- Changing a traveler's last name and choosing "Save traveler changes" shows
  the new name in the saved travelers list.
- Reloading the Account page still shows the new name.
- Saving with an empty last name shows an error, and the saved traveler keeps
  its previous name.
- Cancel closes the edit form without changing the traveler.
